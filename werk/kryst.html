Project Overzicht

Een volledige WordPress website voor Kryst BV — een startup die betekenisvolle christelijke kerstverlichting verkoopt. Ontworpen in Figma door groepsgenoot Linda en door mij gebouwd als custom WordPress theme vanuit VSCode, lokaal gehost via Local.

Toegepaste Skills

  • WordPress
  • Custom Theme
  • PHP
  • HTML & CSS
  • Figma
  • Local (WP)

De Uitdaging

Een authentieke christelijke identiteit vertalen naar een moderne webshop die vertrouwen opbouwt voor een pre-order model — zonder niche over te komen. Tegelijk moest het Figma-ontwerp van Linda pixel-perfect worden gebouwd als functioneel WordPress theme.

De Oplossing

Custom WordPress theme geschreven in VSCode met PHP templates, eigen CSS en een lokale dev-omgeving via Local. Het design sluit aan op Figma (Linda's ontwerp) en volgt de 8 design principles van het project: transparantie, rustige vormgeving, eerlijke productpresentatie en social proof.

Werkwijze

01

Figma Ontwerp Analyse

Het ontwerp van Linda bestudeerd: kleuren, componenten, typografie en responsieve breakpoints in kaart gebracht voordat ik code schreef.

02

Custom Theme Opzet

WordPress theme-structuur opgezet in VSCode: style.css, functions.php, index.php en losse page templates per pagina.

03

Lokale Dev met Local

Lokale WordPress-omgeving opgezet via Local by Flywheel. Zo kon ik snel itereren en het theme live testen zonder hosting.

04

Pre-order & Content

Producten aangemaakt in WooCommerce, pre-order logica ingesteld en contentelementen (blog, testimonials, impact-sectie) toegevoegd.

Frontend developer & designer met een passie voor design en techniek.
