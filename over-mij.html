Over mij

Passie voor techniek en design, gecombineerd in elk project

Frontend Developer

Mijn naam is Mischa Leijder Havenstroom. Ik ben een tweedejaars CMD-student en ik richt mij op frontend development. Websites bouwen die er goed uitzien én technisch goed werken, dat is wat mij drijft.

Mijn technische skills heb ik voor een groot deel opgebouwd via Scrimba, een online leerplatform voor developers. Buiten school om heb ik daar actief mee gewerkt aan HTML, CSS en JavaScript. Als ik iets niet weet, zoek ik het op. Als iets niet werkt, blijf ik proberen totdat het wél werkt.

Voordat ik begin met coderen, werk ik mijn ontwerpen altijd eerst uit in Figma. Lay-out, kleuren en typografie staan vast voordat er een regel code geschreven wordt. Mijn achtergrond in MBO Mediavormgeving helpt daarbij, want ik heb geleerd werken met Illustrator, Photoshop en InDesign, waardoor ik design echt begrijp en niet alleen als developer die iets mooi wil maken.

Ik wil mij verder ontwikkelen in JavaScript en frameworks zoals React, en meer ervaring opdoen met Git in een professionele omgeving. Ik zoek een stageplek in Groningen waar ik als frontend developer aan echte projecten kan werken en kan leren van mensen met meer ervaring.

Frontend development is de richting waar ik naartoe wil. Dit portfolio laat zien waar ik nu sta.
